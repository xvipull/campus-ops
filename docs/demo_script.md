# Five-Minute Demo Script

1. **Open the executive view (0:00–0:45).** Explain the problem: leaders need one governed view of enrollment, planning variance, and instructional capacity. Point out active enrollment, credit hours, withdrawal rate, and highest resource pressure.
2. **Show trend and diagnostic context (0:45–1:30).** Filter Fall 2026 and compare departments. Use the trend page to show the period-over-period change and the diagnostic matrix to locate negative plan variance.
3. **Explain the planning decision (1:30–2:30).** Open resource scenarios. CS is rank 1 because faculty SCH capacity, not room availability, drives pressure. Switch from baseline to growth or change Excel’s amber growth input to show the updated pressure.
4. **Review the exception (2:30–3:15).** Show the Business Administration forecast variance. Explain that this calls for forecast validation before staffing expansion.
5. **Prove trust and governance (3:15–4:15).** Open Data Quality. Show all three reconciliation controls passing, the documented tolerance, and the Definitions page with metric owner/grain/source.
6. **Close with delivery readiness (4:15–5:00).** Show the raw-to-staging-to-star-schema architecture and explain that the same governed SQLite model supports Power BI and Excel. Note that the sample is synthetic and production requires approved FERPA/RBAC controls.
